# 데모 녹화 가이드

제출용 시연 영상(1–2분)과 2차 PT 현장 시연을 같은 순서로 준비합니다. 에뮬레이터 설치·세팅은 [EMULATOR_QA.md](EMULATOR_QA.md)를 봅니다.

## 준비물

| 항목 | 내용 |
| --- | --- |
| 차량 | Pleos Connect Emulator v2.1.0(API 34) + Virtual Console |
| 폰 | 일반 폰 에뮬레이터(API 34) 또는 실제 폰(같은 Wi-Fi, `-Ppleos.apiBaseUrl=http://<PC IP>:8090/`) |
| 서버 | BE 저장소 `./gradlew bootRun` (8090이 사용 중이면 `--args='--server.port=18090'`로 띄우고 앱 주소도 맞춤) |
| 빌드 | 두 앱 모두 **디버그 빌드**(시연 버튼은 디버그에만 있음) |

## 시연 순서 (약 2분)

| # | 화면 | 하는 일 | 보여줄 것 |
| --- | --- | --- | --- |
| 1 | 차량 | 앱 실행 | 연결 코드 6자리 |
| 2 | 폰 | 가입 → 코드 입력 | 차량 화면이 "함께 탈 준비가 됐어요"로 바뀜 |
| 3 | 폰 | 내 컨디션: 멀미 "잘 타요" · 쉬는 방식 "바깥 바람" | 가족마다 다른 설정 |
| 4 | 차량 | Virtual Console 운전석 점유 끔→켬, 기어 P (또는 "지금 출발") | 트립 자동 시작 |
| 5 | 차량 | 시연 패널 **▶ 가족 나들이** | 약 1분 자동 재생: 출발 → 가다 서다 → 급커브 예고 → 구불길(멀미 주의) → 휴게소 12km → 지나감 → 도착 |
| 6 | 차량 | 도착 화면에서 "30초 숨 고르기" | 이동 45분·막힌 시간·급커브 4곳·최고 위험도 요약, 호흡 원 |
| 7 | 폰 | 홈 "오늘 이동 어땠나요?" → 기분 + 한 줄 | 기록 탭 "이번 주" 요약 |

- 자동 재생 중에는 화면이 주행 상태(버튼 숨김)로 바뀌고, 끝나면 정차 상태로 돌아와 도착 화면이 뜹니다.
- 자동 재생은 실제 신호와 같은 계산 경로를 탑니다. 이동·막힘 시간은 시연 시간을 줄이려고 앞당겨 쌓습니다(영상 자막에 "시연용 신호"라고 표기).
- 브레이크·핸들은 자동 재생 대신 Virtual Console로 직접 보여 줄 수도 있습니다(EMULATOR_QA S5‴).

## 녹화

차량 화면(에뮬레이터 시리얼은 `adb devices`로 확인):

```bash
adb -s emulator-5554 shell screenrecord --time-limit 180 /sdcard/shwimpyo_car.mp4
```

```bash
adb -s emulator-5554 pull /sdcard/shwimpyo_car.mp4 .
```

폰 화면도 같은 방법(`emulator-5556` 등)으로 따로 녹화한 뒤 이어 붙입니다. 두 화면을 나란히 놓으려면:

```bash
ffmpeg -i shwimpyo_car.mp4 -i shwimpyo_phone.mp4 -filter_complex "[0:v]scale=-2:720[a];[1:v]scale=-2:720[b];[a][b]hstack" -an shwimpyo_demo.mp4
```

## 영상에 넣을 자막(예)

1. "차는 앞길을 알고 있습니다" — 연결·탑승
2. "2km 앞 급커브 3곳, 미리 대비해요" — 위험도와 이유
3. "가족이 고른 쉬는 방식으로" — 바깥 바람 권유, 휴게소
4. "도착하면 30초 쉼표" — 요약·숨 고르기
5. "기분은 내가 남겨요" — 폰 체크인·이번 주 요약
